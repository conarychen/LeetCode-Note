# [20. Valid Parentheses](https://leetcode.com/problems/valid-parentheses/description/)  
目標 -> 判斷input是否為成對(合理)的括弧  
用Stack存 如果進來的是左括號就push進stack  
如果是右括號 那就看stack top的左括號是否可以跟目前的右括號配對  
如果可以就pop掉 直到全部看完後  
stack如果空的 就代表是合理的 否則就是有問題  
```cpp
class Solution {
public:
    bool isValid(string s) {
        vector<char> stack;
        char temp = ' ';
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( stack.empty() != 0 ) {
                stack.push_back( s[i] );
            }
            else {
                temp = stack[stack.size()-1];
                if ( ( s[i] == ')' && temp == '(' ) ||
                     ( s[i] == ']' && temp == '[' ) ||
                     ( s[i] == '}' && temp == '{' ) ) {
                    stack.pop_back();
                }
                else {
                    stack.push_back( s[i] );
                }
            }
        }
        if ( stack.empty() != 0 ) return true;
        else return false;
    }
};
```
