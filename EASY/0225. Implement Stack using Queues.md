# [225. Implement Stack using Queues](https://leetcode.com/problems/implement-stack-using-queues/description/)  
目標 -> 用queue實做stack  
因為queue stack特性剛好相反  
所以在排序上要稍微處理  
這題用一個queue來做  
最主要處理的就是當有新資料push進來時 因為stack是FILO  
所以要把新資料放到queue的top  
那就代表要把前面的所有資料都pop出來再push回去  
也有另一種方法是利用兩個queue 在[232](https://github.com/conarychen/LeetCode-Note/blob/main/EASY/0232.%20Implement%20Queue%20using%20Stacks.md)就是利用這種方法  
```cpp
class MyStack {
public:
    queue<int> que;
    MyStack() {
        while ( que.size() != 0 ) {
            que.pop();
        }
    }
    
    void push(int x) {
        int temp, Qsize = que.size();
        que.push(x);
        for ( int i = 0 ; i < Qsize ; i++ ) {
            temp = que.front();
            que.pop();
            que.push(temp);
        }
    }
    
    int pop() {
        int tar = que.front();
        que.pop();
        return tar;
    }
    
    int top() {
        return que.front();
    }
    
    bool empty() {
       if ( que.size() == 0 ) {
        return true;
       }
       return false; 
    }
};

/**
 * Your MyStack object will be instantiated and called as such:
 * MyStack* obj = new MyStack();
 * obj->push(x);
 * int param_2 = obj->pop();
 * int param_3 = obj->top();
 * bool param_4 = obj->empty();
 */
```
