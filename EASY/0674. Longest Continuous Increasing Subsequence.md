# [674. Longest Continuous Increasing Subsequence](https://leetcode.com/problems/longest-continuous-increasing-subsequence/description/)  
目標 -> 找到最長連續遞增子序列  
遍歷一次 把數字存在deque 如果新的數大於deque尾端的樹那就推進去 繼續數  
如果遇到小於的 那就代表中斷了 先看目前長度有沒有超過原先紀錄的 有就更新一下  
然後清空deque 繼續找下一組  
```cpp
class Solution {
public:
    int findLengthOfLCIS(vector<int>& nums) {
        int max = 0;
        deque<int> dq;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( dq.size() == 0 ) {
                dq.push_back( nums[i] );
            }
            else {
                if ( nums[i] <= dq.back() ) {
                    if ( dq.size() > max ) {
                        max = dq.size();
                    }
                    dq.clear();
                }
                dq.push_back( nums[i] );
            }
        }
        if ( dq.size() > max ) max = dq.size();
        return max;
    }
};
```
