# [9. Palindrome Number](https://leetcode.com/problems/palindrome-number/description/)  
目標 -> 判斷數字是否為回文  
把數字切成一半 如果兩個相等 或是其中一邊扣掉尾就相等 代表是回文  
ex 1221 -> 12 21是回文  121 -> 12 1 -> 12減去2(直接移除一位數) -> 1 1 是回文  
另外如果數字小於10也會是  
```cpp
class Solution {
public:
    bool isPalindrome(int x) {
        int temp = 0;
        if ( ( x % 10 == 0 && x >= 10 ) || x < 0 ) {
            return false;
        }
        else if ( x < 10 ) {
            return true;
        }
        while ( temp < x ) {
            temp = (temp * 10) + (x % 10);
            x /= 10;
        }

        if ( temp == x || ( temp /= 10 ) == x ) {
            return true;
        }
        else {
            return false;
        }
    }
};
```
