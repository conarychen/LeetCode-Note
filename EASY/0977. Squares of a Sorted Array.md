# [977. Squares of a Sorted Array](https://leetcode.com/problems/squares-of-a-sorted-array/description/)  
目標 -> 把nums裡的數平方後排列  
這邊我偷懶用map存平方數  
因為map會排列  
所以再走訪一次把平方且排列好的數取出即可  
```cpp
class Solution {
public:
    vector<int> sortedSquares(vector<int>& nums) {
        map<int,int> mp; //map 照key值大小排序
        int temp;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            temp = nums[i] * nums[i];
            if ( mp.find(temp) != mp.end() ) {
                mp[temp]++;
            }
            else {
                mp[temp] = 1;
            }
        }
        vector<int> result;
        for ( auto [key,val] : mp ) {
            for ( int i = 0 ; i < val ; i++ ) {
                result.push_back( key );
            }
        }
        return result;
    }
};
```
