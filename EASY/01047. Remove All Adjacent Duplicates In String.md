# [1047. Remove All Adjacent Duplicates In String](https://leetcode.com/problems/remove-all-adjacent-duplicates-in-string/description/)  
目標 -> 刪除兩個相鄰且相同的字母 直到字串內都沒有  
Input: s = "abbaca" -> "aaca" -> "ca"  
我用stack 只要目前的字母跟stack的top相同 那stack就pop掉  
若不同就push進去  
最後把stack倒著放進string就好(其實直接用deque好像比較方便 但其實vector也差不多了取的時候也可以倒者取)  
```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        vector<char> stack;
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( i > 0 && stack.size() > 0 && s[i] == stack[stack.size()-1] ) {
                stack.pop_back();
            }
            else {
                stack.push_back( s[i] );
            }
        }
        string result = "";
        for ( int i = 0 ; i < stack.size() ; i++ ) {
            result += stack[i];
        }
        return result;
    }
};
```
