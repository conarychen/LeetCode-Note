# [121. Best Time to Buy and Sell Stock](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/)  
目標 -> 可以選一天購買股票 並在其後的天數選一天賣出 找出最大獲利  
我從後面開始找最大價值 每輪除了維護最大值外 也要計算獲利  
同一輪如果最大值改變 那獲利絕對是0 -> 當天買又賣  
但如果該輪最大值不變 那就代表會產生新獲利  
如果新獲利比先前找到的更大 就記起來即可  
```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int maxP = 0, maxR = 0;
        for ( int i = prices.size()-1 ; i >= 0 ; i-- ) {
            if ( i == prices.size()-1 ) {
                maxR = prices[i];
            }
            else {
                if ( prices[i] > maxR ) {
                    maxR = prices[i]; 
                }
            }
            if ( maxP < ( maxR-prices[i] ) ) {
                maxP = maxR-prices[i];
            }
        }
        return maxP;
    }
};
```
