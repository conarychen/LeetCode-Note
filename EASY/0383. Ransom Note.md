# [383. Ransom Note](https://leetcode.com/problems/ransom-note/description/)  
目標 -> ransomNote(a) magazine(b) 求a能不能用b的字母拼出來 b內的每個字元只能用一次(a如果需要qq 那b裡面就要有兩個q)  
一樣用map計算b用了哪些以及多少  
再用a的字元當key 如果有找到就count-- 如果沒找到or count<0代表a多用  
```cpp
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        unordered_map<char,int> map;
        bool result = true;
        for ( int i = 0 ; i < magazine.size() ; i++ ) {
            if ( map.find( magazine[i] ) != map.end() ) {
                map[magazine[i]]++;
            }
            else {
                map[magazine[i]] = 1;
            }
        }
        for ( int i = 0 ; i < ransomNote.size() && result ; i++ ) {
            if ( map.find( ransomNote[i] ) != map.end() ) {
                if ( map[ransomNote[i]] > 0 ) {
                    map[ransomNote[i]]--;
                }
                else {
                    result = false;
                }     
            }
            else {
                result = false;
            }

        }
        return result;
    }
};
```
