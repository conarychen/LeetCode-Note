# [704. Binary Search](https://leetcode.com/problems/binary-search/description/)  
目標 -> 二元搜尋target(nums為排列好的)  
left = 0(開頭) right = 最後的index(尾) mid = left + left和right的差值除以2(這樣保證往右找)  
如果mid位置的值太小 那就是left = mid+1 反之right = mid-1  
如果找不到的情況就會打破left <= right的規則跳出去  
```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size()-1, mid;
        bool isDone = false;
        while ( left <= right ) {
            mid = left + (right-left)/2;
            
            if ( nums[mid] == target ) {
                left = right+1;
            }
            else if ( nums[mid] < target ) {
                left = mid+1;
            }
            else {
                right = mid-1;
            }
        }
        if ( nums[mid] != target ) {
            mid = -1;
        }
        return mid;
    }
};
```
