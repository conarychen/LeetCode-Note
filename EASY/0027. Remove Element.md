# [27. Remove Element]()  
目標 -> 刪除nums內為val的元素  
我這邊是真的刪除 但其實不用  
一樣計數留下個數最後要回傳  
用一個pointer指向可以交換的位置  
遇到要刪除的就跟pointer指向的位置交換  
因為題目不要求後面擺甚麼  
這樣就可以減少一直搬動vector的成本  
```cpp
class Solution {
public:
    int removeElement(vector<int>& nums, int val) {
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( nums[i] == val ) {
                nums.erase( nums.begin() + i );
                i--;
            }
        }
        return nums.size();
    }
};
```
