# [496. Next Greater Element I](https://leetcode.com/problems/next-greater-element-i/description/)  
目標 -> 找出nums1的數字 在nums2位置上後面一個比他大的數 (很難懂 題目也寫得很難懂)  
Input: nums1 = [4,1,2], nums2 = [1,3,4,2]  
Output: [-1,3,-1]  
nums1[0] = 4 在nums2中 4在 index = 2的地方 而index > 2 沒有大於4的數 所以output = -1  
nums1[1] = 1 nums2中是 index = 0 在index > 0 第一個大於1的數是2 所以取 3  
nums1[2] = 2 nums2中是 index = 3 已經是最後了 不可能有其他 所以取 -1  
按照這想法 其實很單純就是幫nums2的所有數字找他後面第一個比自己大的數  
只是回傳順序按照nums1  
所以利用stack 如果目前數字比stack大 那就pop出來 記錄到map (pop出來的當key 而比他大的值當val)  
一直做到stack空了 或是目前數字比裡面小 那就把目前數字push進去  
直到做完nums2的長度 stack裡剩下的就是找不到的 一樣記錄到map上 val為-1  
最後用nums1的值當key取我們要的val  
```cpp
class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        unordered_map<int,int> mp;
        stack<int> st;
        vector<int> result;
        for ( int i = 0 ; i < nums2.size() ; i++ ) {
            if ( i == 0 ) {
                st.push( nums2[i] );
            }
            else {
                while( st.size() != 0 && nums2[i] > st.top() ) {
                    mp[st.top()] = nums2[i];
                    st.pop();
                }
                st.push( nums2[i] );
            }
        }
        while ( st.size() != 0 ) {
            mp[st.top()] = -1;
            st.pop();
        }
        for ( int i = 0 ; i < nums1.size() ; i++ ) {
            result.push_back( mp[nums1[i]] );
        }
        return result;
    }
};
```
