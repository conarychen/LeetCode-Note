# [58. Length of Last Word](https://leetcode.com/problems/length-of-last-word/description/)  
目標 -> 找到最後一個詞的長度  
把所有詞都用stringstream都取出來(他會跳過空格)  
最後取最後一個的長度即可  
```cpp
class Solution {
public:
    int lengthOfLastWord(string s) {
        stringstream ss(s);
        string temp;
        vector<string> vec;
        while ( ss >> temp ) {
            vec.push_back( temp );
        }
        return vec[vec.size()-1].size();
    }
};
```
