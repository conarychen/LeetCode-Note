# [70. Climbing Stairs](https://leetcode.com/problems/climbing-stairs/description/)  
目標 -> 每次可走1~2步 走到n(頂)  
利用DP來找  
因為每次可以走1~2步 -> 也就是dp[i] = dp[i-1]+dp[i-2]  
```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> dp;
        // base case
        dp.push_back( 1 ); //到第一層 可以選擇 1步 --> 1種
        dp.push_back( 2 ); //到第二層 可以選擇 1+1步 or 2步 --> 2種
        if ( n > 2 ) {
            for ( int i = 2 ; i < n ; i++ ) {
                dp.push_back( dp[i-1]+dp[i-2] );
            }
        }
        return dp[n-1];
    }
};
```
