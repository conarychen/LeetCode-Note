# [232. Implement Queue using Stacks](https://leetcode.com/problems/implement-queue-using-stacks/description/)  
目標 -> 利用stack來製作queue
queue和stack特性完全相反 -> FIFO vs FILO  
這邊利用兩個stack 一個為接收input的queue(in) 另一個則是處理output的queue(out)  
當out空了的時候 就把in的內容依序丟進去out -> 因為stack特性 所以這樣會是out = in的倒序 也就是我們想要的FIFO  
而另一作法就是僅利用一個queue 每次push新東西進來 都重新整理順序  
這作法在[225](https://github.com/conarychen/LeetCode-Note/blob/main/EASY/0225.%20Implement%20Stack%20using%20Queues.md)  
```cpp
class MyQueue {
public:
    stack<int> instack; //catch input
    stack<int> outstack; // reverse input order to simulate queue

    MyQueue() {
        while( instack.size() != 0 ) {
            instack.pop();
        } 
        while( outstack.size() != 0 ) {
            outstack.pop();
        }   
    }

    void inTOout() {
        while ( instack.size() != 0 ) {
            outstack.push( instack.top() );
            instack.pop();
        }
    }
    
    void push(int x) {
        instack.push(x);
    }
    
    int pop() {
        if ( outstack.size() == 0 ) {
            inTOout();
        }
        int tar = outstack.top();
        outstack.pop();
        return tar;
    }
    
    int peek() {
        if ( outstack.size() == 0 ) {
            inTOout();
        }
        return outstack.top();
    }
    
    bool empty() {
        if ( instack.size() == 0 && outstack.size() == 0 ) {
            return true;
        }
        return false;
    }
};

/**
 * Your MyQueue object will be instantiated and called as such:
 * MyQueue* obj = new MyQueue();
 * obj->push(x);
 * int param_2 = obj->pop();
 * int param_3 = obj->peek();
 * bool param_4 = obj->empty();
 */
```
