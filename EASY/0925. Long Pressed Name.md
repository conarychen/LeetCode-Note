# [925. Long Pressed Name](https://leetcode.com/problems/long-pressed-name/description/)  
目標 -> 看看typed是不是想打出name  
Input: name = "alex", typed = "aaleex"  
Output: true  
簡單來說看typed按的是不是name的內容 多按只能容忍同個字重複按到  
首先確認name的長度必須 <= typed的  
接下來就一個一個比  
如果比到不同的 要確認一下typed是不是重複上一個字母  
是的話把typed往下找到不同的子母 再來比  
跑完後要看typed也結束了沒  
如果後面還有字母 就要看是不是都是重複的 否則多按其他的也不行  
```cpp
class Solution {
public:
    bool isLongPressedName(string name, string typed) {
        if ( typed.size() < name.size() ) return false;
        int j = 0;
        bool isDone = false;
        for ( int i = 0 ; i < name.size() && j < typed.size() ; i++ ) {
            if ( i == 0 && name[i] != typed[j] ) return false;

            if ( name[i] != typed[j] ) {
                if ( typed[j] == typed[j-1] ) {
                    while ( typed[j] == typed[j-1] ) j++;
                    i--;
                }
                else {
                    return false;
                }
            }
            else {
                if ( i == name.size()-1 ) isDone = true;
                j++;
            }
        }

        if ( j != typed.size() ) {
            
            while ( j < typed.size() ) {
                if ( typed[j] != typed[j-1] ) return false;
                j++;
            }
        }
        return isDone;
    }
};
```
