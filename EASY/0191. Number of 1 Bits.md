# [191. Number of 1 Bits](https://leetcode.com/problems/number-of-1-bits/description/)  
目標 -> 計算n若換成二進制會有幾個1  
n和1做聯集(&) -> 也就是取最右邊的一個bit 判斷這個bit是不是1 是的話count++ 然後n右移位 繼續32次(int 32bits)  
```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int count = 0;
        for ( int i = 0 ; i < 32 ; i++ ) {
            if ( n & 1 == 1 ) {
                count++;
            }
            n >>= 1;
        }
        return count;
    }
};
```
