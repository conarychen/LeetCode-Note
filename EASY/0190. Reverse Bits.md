# [190. Reverse Bits](https://leetcode.com/problems/reverse-bits/description/)  
目標 -> 把input的int利用bit運算反轉  
n -> input數字 temp -> 每次取n的第一個bit result -> 存結果  
流程 -> result向左移1位 -> temp為n的最右邊第一個bit -> n被取走最右bit 所以向右移1位 -> result加上temp  
可以看成  
result = 0001 -> 0010 -> n = 1101 -> temp = 1 -> n = 0110 -> result + temp = 0011
```cpp
class Solution {
public:
    int reverseBits(int n) {
        int temp, result = 0;
        for ( int i = 0 ; i < 32 ; i++ ) {
            result <<= 1;
            temp = n & 1;
            n >>= 1;
            result += temp;
        }
        return result;
    }
};
```
