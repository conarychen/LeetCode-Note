# [541. Reverse String II](https://leetcode.com/problems/reverse-string-ii/description/)  
目標 -> 反轉k個字元的順序 並隔k個字元再繼續反轉 (不明所以的要求)  
Input: s = "abcdefg", k = 2  
Output: "bacdfeg"  
ab轉 隔兩個(cd) ef轉 g剩下一個沒得轉 (但假如k = 3 剩下兩個字元 也要轉)  
就每隔兩倍的k反轉一次 要傳反轉的頭尾  
```cpp
class Solution {
public:
    void reverseString(string &s, int start, int end, int k ) {
        int e = end;
        if ( end >= s.size() ) {
            e = s.size()-1;
        }
        if ( k > 2 ) {
            for ( int i = start, j = e ; i <= start+((e-start)/2) ; i++, j-- ) {
                swap( s[i], s[j] );

            }
        }
        else if ( k == 2 ) {
            swap( s[start], s[e] );
        }

        
    }
    string reverseStr(string s, int k) {
        for ( int i = 0 ; i < s.size() ; i+=2*k ) {
            reverseString( s, i, i-1+k, k );
        }
        return s;
    }
};
```
