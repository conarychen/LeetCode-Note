# [724. Find Pivot Index](https://leetcode.com/problems/find-pivot-index/description/)  
目標 -> 找到pivot index 此處pivot指的是左右兩側和相等的點  
先算總和 接著就一個一個加  
left + right = sum - nums[i]  
left(+pivot) + right(+pivot) = sum + nums[i]  
right(+pivot) = sum - left(+pivot) + nums[i] (pivot)  
所以當找到left == right代表找到了 否則沒有pivot  
```cpp
class Solution {
public:
    int pivotIndex(vector<int>& nums) {
        int sum = 0;
        for ( int i = 0 ; i < nums.size() ; i++ ) sum+=nums[i];
        int left = 0, right = 0;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            left += nums[i]; //左半+pivot
            right = sum - left + nums[i]; //右半+pivot
            if ( left == right ) return i;
        }
        return -1;
    }
};
```
