# [p101. Symmetric Tree](https://leetcode.com/problems/symmetric-tree/description/)  
目標 -> 確認樹是否為鏡像的(對稱)  
與[100](https://github.com/conarychen/LeetCode-Note/blob/main/EASY/0100.%20Same%20Tree.md)很像  
只是100是在比較左右都相同  
而此題的對稱要是A的左要等於B的右 A的右要等於B的左  
所以判斷條件一樣 只是call的時候要把左右子樹交換  
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
private:
    bool compareNode( TreeNode *left, TreeNode *right ) {
        if ( left == NULL && right != NULL ) return false;
        else if ( left != NULL && right == NULL ) return false;
        else if ( left == NULL && right == NULL ) return true;
        else if ( left -> val != right -> val ) return false;
        else return compareNode( left->left, right->right ) && compareNode( left-> right, right -> left );
    }
public:
    bool isSymmetric(TreeNode* root) {
        return compareNode( root -> left, root -> right );
    }
};
```
