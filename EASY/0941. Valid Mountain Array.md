# [941. Valid Mountain Array](https://leetcode.com/problems/valid-mountain-array/description/)  
目標 -> 確認數字是否為mountain array -> 左邊到peak要是嚴格遞增 && 右邊到peak也要是嚴格遞增  
左邊一直走到i > i+1的地方停下 右邊則是i > i-1  
最後比較兩個停下的地方是不是相同 並且不可以是邊邊(0 or 陣列尾)  
```cpp
class Solution {
public:
    bool validMountainArray(vector<int>& arr) {
        if ( arr.size() < 3 ) return false; 
        int left = 0, right = arr.size()-1;

        while ( left < arr.size()-1 && arr[left] < arr[left+1] ) {
            left++;
        }
        while ( right > 0 && arr[right] < arr[right-1] ) {
            right--;
        }

        return left == right && ( left != 0 && right != arr.size()-1 );
    }
};
```
