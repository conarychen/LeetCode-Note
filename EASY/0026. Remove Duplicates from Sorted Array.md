# [26. Remove Duplicates from Sorted Array](https://leetcode.com/problems/remove-duplicates-from-sorted-array/description/)  
目標 -> 刪除重複元素(留一個)  
利用雙指標 第一個指標負責指向要插入的位置 第二個則是用來走訪  
只要第二個指標指向的值不等於第一個指標指向的 就代表沒重複  
那就可以把第一個指標往下移動 並把第二個指標內的值般過去  
如果相同 第一個指標就不動 讓第二個繼續往下找到不同的即可  
最後把多出來的都pop掉 但這步驟有點多餘 其實只要計數要留的數量回傳就好  
因為題目不在意後面放了甚麼  
  
我第一次寫的時候每次重複的就刪除(註解內的查表法)  
但這樣要搬動好多次vector 很浪費資源  

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int pointer = 0; //指著上一個插的位置
        for ( int i = 1 ; i < nums.size() ; i++ ) {
            if ( nums[i] != nums[pointer] ) {
                pointer++;
                nums[pointer] = nums[i];
            }
        }
        while ( nums.size()-1 != pointer ) {
            nums.pop_back();
        }


        /* hash查表
        unordered_map<int, bool> map; // 如果有拿到就存成true

        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( map.find( nums[i] ) == 0 ) {
                map[nums[i]] = true;
            }
            else {
                nums.erase( nums.begin() + i );
                i--;
            }
        }
        */
        return nums.size();
    }
};
```
