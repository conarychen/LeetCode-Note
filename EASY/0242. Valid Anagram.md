# [242. Valid Anagram](https://leetcode.com/problems/valid-anagram/description/)  
目標 -> 判斷兩字串是否為Anagram (簡單來說用的字母一樣 但排序不同)  
這邊我用map先記錄其中一個字串的字母  
接著用另一個字串來同個map找 如果有找到 計數-1  
如果沒找到or計數<0代表用的字母or量不同 那就不是Anagram  
```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if ( s.size() != t.size() ) {
            return false;
        }
        unordered_map<char,int> mp;
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( mp.find(s[i]) == mp.end() ) {
                mp[s[i]] = 1;
            }
            else {
                mp[s[i]]++;
            }
        }
        bool result = true;
        for ( int i = 0 ; i < t.size() && result ; i++ ) {
            if ( mp.find(t[i]) != mp.end() ) {
                if ( mp[t[i]] > 0 ) {
                    mp[t[i]]--;
                }
                else {
                    result = false;
                }
            }
            else {
                result = false;
            }
        }
        return result;
    }
};
```
