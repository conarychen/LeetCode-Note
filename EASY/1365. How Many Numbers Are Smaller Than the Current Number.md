# [1365. How Many Numbers Are Smaller Than the Current Number](https://leetcode.com/problems/how-many-numbers-are-smaller-than-the-current-number/description/)  
目標 -> 找出小於自身的數有多少個  
利用排序後 index就是小於自己的數量 由後往前就可以蓋過重複的  
接著用map存起後  
再按照原本的順序取出即可  
```cpp
class Solution {
public:
    vector<int> smallerNumbersThanCurrent(vector<int>& nums) {
        vector<int> result( nums.size(), 0 );
        if ( nums.size() == 0 ) return result;
        vector<int> copyy = nums;
        sort( copyy.begin(), copyy.end() );
        unordered_map<int,int> mp;
        // 排序後index就等於有多少小於自己的數 後向前 就可以把重複的蓋過去
        // ex 8,1,2,2,3 -> 1,2,2,3,8 -> 0,1,2,3,4, -> 2會先記錄成2再被覆蓋成1
        for ( int i = copyy.size()-1 ; i >= 0 ; i-- ) {
            mp[copyy[i]] = i;
        }
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            result[i] = mp[nums[i]];
        }
        return result;
    }
};
```
