# [344. Reverse String](https://leetcode.com/problems/reverse-string/description/)  
目標 -> 反轉字串  
頭尾pointer互換 走到字串size的一半就全部換完  
```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        for ( int i = 0, j = s.size()-1 ; i < s.size()/2 ; i++, j-- ) {
            swap( s[i], s[j] );
        }
    }
};
```
