# [509. Fibonacci Number](https://leetcode.com/problems/fibonacci-number/description/)  
目標 -> 計算Fibonacci Number  
這個數列的規則就是n = (n-1) + (n-2)  
所以靠遞迴即可 更好一點可以用個map之類的把算過的紀錄下來 這樣可以避免很多次遞迴呼叫  
```cpp
class Solution {
public:
    int fib(int n) {
        if ( n == 0 ) {
            return 0;
        }
        else if ( n == 1 ) {
            return 1;
        }
        return fib(n-1) + fib(n-2);
    }
};


```
