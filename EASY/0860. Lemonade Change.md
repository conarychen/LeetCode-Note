# [860. Lemonade Change](https://leetcode.com/problems/lemonade-change/description/)  
目標 -> 找錢問題 一杯檸檬水賣$5 會收到 $5 $10 $20 一開始手上沒錢 看顧客付款方式能不能完成找零  
收到$5不用找 就紀錄有一個$5  
$10 看有沒有$5可以找 沒有就失敗 也要記錄有$10  
$20 看有沒有$10+$5 or 3個$5  
```cpp
class Solution {
public:
    bool lemonadeChange(vector<int>& bills) {
        vector<int> have( 3, 0 );
        bool result = true;
        for ( int i = 0 ; i < bills.size() && result ; i++ ) {
            if ( bills[i] == 5 ) {
                have[0]++;
            }
            else if ( bills[i] == 10 ) {
                
                if ( have[0] > 0 ) {
                    have[1]++;
                    have[0]--;
                }
                else {
                    result = false;
                }
            }
            else { // 20

                if ( (have[1] > 0 && have[0] > 0) ) {
                    have[2]++;
                    have[0]--;
                    have[1]--;
                }
                else if ( have[0] > 2 ) {
                    have[2]++;
                    have[0] -= 3;
                }
                else {
                    cout << bills[i] << endl;
                    result = false;
                }
            }
        }
        return result;
    }
};
```
