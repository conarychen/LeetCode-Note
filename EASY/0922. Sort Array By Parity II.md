# [922. Sort Array By Parity II](https://leetcode.com/problems/sort-array-by-parity-ii/description/)  
目標 -> 當vector的index為odd時 內容也要是odd 反之even時內容也要是even  
用一個變數紀錄下一個index odd且內容是even的位置在哪  
每次只要走到even的index就看一下 如果內容是odd 那就跟我們紀錄的odd位置內容交換  
並找下一個內容為even的odd  
```cpp
class Solution {
public:
    vector<int> sortArrayByParityII(vector<int>& nums) {
        int odd = 1;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( i % 2 == 0 && nums[i] % 2 == 1 ) {
                while ( nums[odd] % 2 != 0 ) odd+=2;
                swap( nums[i], nums[odd] );
            }
        }
        return nums;
    }
};
```
