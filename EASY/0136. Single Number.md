#[136. Single Number](https://leetcode.com/problems/single-number/description/)  
目標 -> input vector中除了一個數字只出現一次以外 其他都出現兩次 找出只出現一次的數字  
利用set來記錄出現過的數字 如果出現第二次 就把他刪掉  
最後set內留下的就是答案  
```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        set<int> s;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( s.find( nums[i] ) == s.end() ) {
                s.insert( nums[i] );
            }
            else {
                s.erase( nums[i] );
            }
        }
        int result = *s.begin(); //set is a iterator
        return result;
    }
};
```
