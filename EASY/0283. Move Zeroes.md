# [283. Move Zeroes](https://leetcode.com/problems/move-zeroes/description/)  
目標 -> 把vector中的0都移到後面  
我先走一遍計算有幾個0 並且把找到的0都刪掉  
最後在尾端加上前面有0的數量即可  
```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int count = 0;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( nums[i] == 0 ) {
                count++;
                nums.erase( nums.begin()+i );
                i--;
            }
        }
        for ( int i = 0 ; i < count ; i++ ) {
            nums.push_back( 0 );
        }
        
    }
};
```
