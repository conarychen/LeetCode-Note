# [844. Backspace String Compare](https://leetcode.com/problems/backspace-string-compare/description/)  
目標 -> 如果字元為'#'代表是退格鍵(刪去的那顆鍵) 把字串整理好後看兩個有沒有相同  
那就各遍歷一次 用temp先接 如果目前是'#'那temp就pop一個字元出來 否則push進temp  
最後比較兩個字串即可  
```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        string temp = "";
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( s[i] == '#' ) {
                if ( temp.size() != 0 ) {
                    temp.pop_back();
                }
            }
            else {
                temp.push_back( s[i] );
            }
        }
        s = temp;
        temp.clear();
        for ( int i = 0 ; i < t.size() ; i++ ) {
            if ( t[i] == '#' ) {
                if ( temp.size() != 0 ) {
                    temp.pop_back();
                }
            }
            else {
                temp.push_back( t[i] );
            }
        }
        t = temp;
        return s == t;
    }
};
```
