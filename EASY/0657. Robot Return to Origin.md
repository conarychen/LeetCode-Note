# [657. Robot Return to Origin](https://leetcode.com/problems/robot-return-to-origin/description/)  
目標 -> 根據移動指令 模擬機器人從[0,0]移動 看最後會不會回到原點  
每次移動完就記錄座標 看最後是不是0,0即可  
```cpp
class Solution {
public:
    bool judgeCircle(string moves) {
        int x = 0 , y = 0;
        for ( int i = 0 ; i < moves.size() ; i++ ) {
            if ( moves[i] == 'R' ) x++;
            else if ( moves[i] == 'L' ) x--;
            else if ( moves[i] == 'U' ) y++;
            else if ( moves[i] == 'D' ) y--;
        }
        if ( x == 0 && y == 0 ) return true;
        return false;
    }
};
```
