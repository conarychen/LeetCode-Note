# [746. Min Cost Climbing Stairs](https://leetcode.com/problems/min-cost-climbing-stairs/description/)  
目標 -> 最少花多少可以爬上階梯  
Input: cost = [10,15,20]
Output: 15  
可以從index = 0 or 1開始 要爬到cost.size() 以上面例子就是index = 3 也就是爬出cost的範圍  
所以這邊選從index=1開始 直接爬兩階出去 花15  
利用DP  可以選0or1開始 所以dp[0] dp[1]都不需要成本  
而後面就是爬到i代表是從i-1 or i-2的地方爬來上來  
所以就是min( dp[i-1]+cost[i-1], dp[i-2]+cost[i-2] )  
```cpp
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        vector<int> dp( cost.size()+1, 0 );
        for ( int i = 0 ; i <= cost.size() ; i++ ) {
            if ( i == 0 || i == 1 ) {
                dp[i] = 0;
            }
            else {
                dp[i] = min( dp[i-1]+cost[i-1], dp[i-2]+cost[i-2] );
            }
            
        }
        return dp[cost.size()];
    }
};
```
