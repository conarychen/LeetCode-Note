# [1221. Split a String in Balanced Strings](https://leetcode.com/problems/split-a-string-in-balanced-strings/description/)  
目標 -> 字串內只會有'L' 'R' 將字串分成平衡字串 -> 切成LR數量相等的子字串 計算可以切成幾個  
利用flag來計算L的數量 遇到R就減1 當flag=0時 代表是平衡字串 那就count+1 然後繼續往下找  
```cpp
class Solution {
public:
    int balancedStringSplit(string s) {
        int flag = 0; // L++ R--
        int count = 0;
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( s[i] != 'L' && s[i] != 'R' ) {
                count = 0;
                break;
            }
            else {
                if ( s[i] == 'L' ) {
                    flag++;
                }
                else {
                    flag--;
                }
            }
            if ( flag == 0 ) {
                count++;
            }
        }
        return count;
    }
};
```
