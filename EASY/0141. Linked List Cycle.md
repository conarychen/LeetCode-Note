# [141. Linked List Cycle](https://leetcode.com/problems/linked-list-cycle/description/)  
目標 -> 判斷linked list是否還有環(cycle)  
[142](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0142.%20Linked%20List%20Cycle%20II.md)是延伸題  
利用快慢指標 快指標每次走2步 慢指標走1步 正常情況下當快指標走到尾 慢指標會在list的中間  
但在有迴圈的情況下 他們會走到同一格 所以只要有重疊到 就代表有迴圈 如果快指標走到尾(or 變成NULL)就代表沒有cycle  
```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    bool hasCycle(ListNode *head) {
        if ( head == NULL || head -> next == NULL ) {
            return false;
        }
        ListNode *fast = head, *slow = head;
        bool result = false;
        do {
            fast = fast -> next;
            if ( fast != NULL ) {
                fast = fast -> next;
            }
            slow = slow -> next;
        } while ( fast != slow && fast != NULL );

        if ( fast != NULL ) {
            result = true;
        }
        return result;
    }
};
```
