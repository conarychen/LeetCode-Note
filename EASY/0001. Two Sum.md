# [1. Two Sum]()  
目標 -> 找到兩數和為target  
因為只會有一組解 所以找到後我直接傳回  
簡單來說用map紀錄 如果map內有target-nums[i]的數存在 代表可以組成target 就可以回傳  
```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> map;
        vector<int> result;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( map.find( target-nums[i] ) != map.end() ) {
                return { map[target-nums[i]], i };
            }
            map[nums[i]] = i;
        }
        return result;
    }
};
```
