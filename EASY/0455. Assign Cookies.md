# [455. Assign Cookies](https://leetcode.com/problems/assign-cookies/description/)  
目標 -> 回傳可以滿足幾個小朋友  
input g是小朋友想要的餅乾size s是我有的餅乾size  
兩邊都先排列後 我從餅乾的角度來發  
如果有發出去就可以計數 沒有的話就換下一片餅乾  
num的部分是用來數第幾位小朋友  
如果第一位拿到了 那我們就開始找第二位可以接受的餅乾大小  
直到找到最後沒餅乾可以比了(餅乾都不符合 or 餅乾發完了)就結束  
```cpp
class Solution {
public:
    int findContentChildren(vector<int>& g, vector<int>& s) {
        int count = 0, num = 0;
        sort( g.begin(), g.end() );
        sort( s.begin(), s.end() );
        for ( int i = 0 ; i < s.size() && num < g.size() ; i++ ) { //cookies
            if ( s[i] >= g[num] ) {
                count++;
                num++;
            }
        }

        return count;

    }
};
```
