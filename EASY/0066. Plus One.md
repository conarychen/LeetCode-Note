# [66. Plus One](https://leetcode.com/problems/plus-one/description/)  
目標 -> 把數字加上一  
把數字拆成每個位數分開算  
主要模擬一個bit一個bit計算  
只是是十進位  
```cpp
class Solution {
public:
    vector<int> plusOne(vector<int>& digits) {
        for ( int i = digits.size()-1, add = 0 ; i >= 0 ; i-- ) {
            if ( i == digits.size()-1 ) {
                digits[i] = digits[i] + 1 + add;
            }
            else {
                digits[i] = digits[i] + add;
            }
            
            add = 0;
            if ( digits[i] >= 10 && i != 0 ) {
                add = 1;
                digits[i] -= 10;
            }
            else if ( digits[i] >= 10 && i == 0 ) {
                
                digits[i] -= 10;
                digits.insert( digits.begin(), 1 );
            }
            else {
                i = 0;
            }
        }
        return digits;
    }
};
```
