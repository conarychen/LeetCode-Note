# [125. Valid Palindrome](https://leetcode.com/problems/valid-palindrome/description/)  
目標 -> 將字串中只留下字母和數字且都轉成小寫 判斷是否為回文  
這裡學到兩個STL的函式 isalpha判斷是否為字母 isalnum字母及數字 這很方便 不用自己寫  
照題目要求 先把字串處理成全都是小寫字母跟數字後  
頭尾開始比 直到前後指標相鄰or重疊即可  
```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        bool result = true, isEnd = false;
        string temp("");
        for ( char c:s ) {      // isalpha -> 判斷字母
            if ( isalnum(c) ) { // isalnum -> 判斷數字及字母
                temp += tolower(c); // tolower 轉成小寫
            }
        }

        if ( temp.size() == 0 ) {
            return true;
        }
        int l = 0, r = temp.size()-1;
        while ( !isEnd ) {
            if ( !isEnd && (l == r || l+1 == r) ) {
                isEnd = true;
            }
            if ( temp[l] == temp[r] ) {
                l++;
                r--;
            }
            else {
                result = false;
                isEnd = true;
            }

        }
        return result;
    }
};
```
