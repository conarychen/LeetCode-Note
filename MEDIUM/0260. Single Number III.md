# [260. Single Number III](https://leetcode.com/problems/single-number-iii/description/)  
目標 -> 找出input數列中只出現過一次的數  
利用set來記錄數字有沒有找過了  
沒找過就加進去 有找過就刪掉  
最後剩下的再加進結果裡回傳  
因為這題重複的數只會出現2次才可以這樣  
否則可以用map計數 然後再看那些只出現1次  
```cpp
class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        set<int> s;
        vector<int> result;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            if ( s.find( nums[i] ) == s.end() ) {
                s.insert( nums[i] );
            }
            else {
                s.erase( nums[i] );
            }
        }
        for ( int i:s ) {
            result.push_back( i );
        }
        return result;
    }
};
```
