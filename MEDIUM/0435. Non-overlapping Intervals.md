# [435. Non-overlapping Intervals](https://leetcode.com/problems/non-overlapping-intervals/description/)  
目標 -> 刪除重疊的區間 回傳最少的刪除數量  
先排序 以開頭大小 如果相同 就再比結尾  
先以第一個的結尾當作point 每走一步 就把新的開頭跟point比  
如果point比較大 那就代表有重疊了(前面的尾>後面的頭)  
因為這邊只是問要刪幾個 所以不用真的刪 用count計數就好  
count++後 比對point還是後面的尾誰比較小就取誰 因為要找刪除最小 所以盡量把使用的區間取小  
如果沒有重疊 那也要更新point = 後面的尾  
```cpp
class Solution {
private:
    static bool cmp( vector<int> & a, vector<int> & b ) {
        if ( a[0] != b[0] ) return a[0] < b[0];
        return a[1] < b[1];
    }
public:
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        sort( intervals.begin(), intervals.end(), cmp );
        int count = 0;

        int point = intervals[0][1];
        for ( int i = 1 ; i < intervals.size() ; i++ ) {
            if ( intervals[i][0] >= point ) {
                point = intervals[i][1]; //renew point
            }
            else {
                count++;
                point = min( point, intervals[i][1] );
            }
        }
        return count;
    }
};
```
