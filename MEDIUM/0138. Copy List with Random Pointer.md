# [138. Copy List with Random Pointer](https://leetcode.com/problems/copy-list-with-random-pointer/description/)  
目標 -> deep copy題目的linked list  
主要是這題比一般的list多了一個random的pointer  
我先把除了random以外的東西都複製好  
並且用hash放(origin node, copy node)  
這樣遍歷一次hash就可以把random連結好  
```cpp
/*
// Definition for a Node.
class Node {
public:
    int val;
    Node* next;
    Node* random;
    
    Node(int _val) {
        val = _val;
        next = NULL;
        random = NULL;
    }
};
*/

class Solution {
public:
    Node* copyRandomList(Node* head) {
        unordered_map<Node*, Node*> mp;
        // map is like
        // key:original node we got / val:duplicate one
        // so we can follow the map to find which node we want
        Node* dummy = new Node(0);
        
        //Node* newHead = new Node( head-> val );
        Node* tar = dummy;
        for ( Node* temp = head ; temp != NULL ; temp = temp -> next ) {
            tar -> next = new Node( temp -> val );
            tar = tar -> next;
            tar -> next = NULL;
            mp[temp] = tar;   
        } // set normal list
        // set random
        for ( Node* temp = head, *tar = dummy -> next ; temp != NULL ; temp = temp -> next, tar = tar -> next ) {
            if ( temp -> random != NULL ) {
                tar -> random = mp[temp -> random];
            }
            else {
                tar -> random = NULL;
            }
            
        }
        return dummy -> next;
    }
};
```
