# [4084. Last Visited Cell in a Directional Grid](https://leetcode.com/problems/last-visited-cell-in-a-directional-grid/description/)  
目標 -> 按照格子內的指令移動 如果下一格是走過的or超出矩陣範圍就停止  
沒什麼特別的 就看本格的行動 然後看一下行動後是可以的嗎 可以就行動並把本格改成'0'代表走過 不行就結束  
x y是移動座標 來記錄目前在哪以及下一動會到哪  
```cpp
class Solution {
public:
    vector<int> lastVisitedCell(vector<vector<char>>& grid) {
        int x = 0 , y = 0;
        bool isDone = false;
        while ( !isDone ) {
            
            if ( grid[x][y] == 'D' && x+1 < grid.size() && grid[x+1][y] != '0' ) {
                grid[x][y] = '0';
                x++;
            }
            else if ( grid[x][y] == 'U' && x-1 >= 0 && grid[x-1][y] != '0' ) {
                grid[x][y] = '0';
                x--;
            }
            else if ( grid[x][y] == 'R' && y+1 < grid[0].size() && grid[x][y+1] != '0' ) {
                grid[x][y] = '0';
                y++;
            }
            else if ( grid[x][y] == 'L' && y-1 >= 0 && grid[x][y-1] != '0' ) {
                grid[x][y] = '0';
                y--;
            }
            else {
                isDone = true;
            }
        }
        vector<int> result( 2, 0 );
        result[0] = x;
        result[1] = y;
        return result;
    }
};
```
