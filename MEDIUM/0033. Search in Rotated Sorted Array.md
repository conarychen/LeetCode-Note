# [33. Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/description/)
目標 -> 在給定的數組中找到target值  
input -> 可能經過旋轉的數列(旋轉前是遞增數列)  
output -> target所在的index  
先找pivot 也就是nums[i] > nums[i+1]的地方(有旋轉過才會有) pivot可以是i or i+1 這裡我用i+1  
如果有找到代表有旋轉 那利用target和nums[pivot]比較就可以知道target會落在pivot左或右側  
如果沒找到 就代表nums沒被旋轉過 是正常的遞增數列  
接著用binary search找target 找到回傳index否則回傳-1  

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size()-1, mid = 0;
        int result = 0, pivot = 0;
        bool isEnd = false;


        if ( nums.size() == 1 ) {

            if ( target == nums[0] ) {
                result = 0;
            }
            else {
                result = -1;
            }
        }
        else {
            //find pivot
            for ( int i = 0 ; i+1 < nums.size() ; i++ ) {
                if ( nums.size() > 1 && nums[i] > nums[i+1] ) {
                    pivot = i+1; 
                    i = nums.size();
                    //find first one
                }
            }

            // find target,  if > nums[1] -> left part(0~pivot-1) else right part
            if ( pivot != 0 ) {
                if ( target >= nums[0] ) {
                    left = 0;
                    right = pivot-1;
                }
                else {
                    left = pivot;
                    right = nums.size()-1;
                }
            }
            else { // rotate did not occur
                left = 0;
                right = nums.size()-1;
            }

            
            while ( !isEnd && left <= right ) { //binary search for target
                
                mid = left + ( right - left ) / 2;
                
                if ( target == nums[left] || target == nums[right] ) {
                    
                    if ( target == nums[left] ) {
                        result = left;
                    }
                    else {
                        result = right;
                    }
                    isEnd = true;
                }
                else { 
                    if ( target < nums[mid] ) {
                        right = mid - 1;
                    }
                        else if ( target > nums[mid] ) {
                        left = mid + 1;
                    }
                    else {
                        result = mid;
                        isEnd = true;
                    }
                }

            }
            if ( isEnd == false ) {
                result = -1;
            }
            
        }

        return result;

    }
};
```
