# [503. Next Greater Element II](https://leetcode.com/problems/next-greater-element-ii/description/)  
目標 -> 找出對每個數來說 下個比自己大的數(如果跑到vec尾端要再重頭開始找 直到找回自己的位置都沒有就是-1)  
因為這題會需要跑到底後再重頭繼續 所以就設定跑2倍的迴圈 而index部分就用取餘(%)的部分可以解決  
我用stack存數字 如果目前數字大於stack top的數字 那就可以取出來存  
直到stack空了 或是top的數字大於目前數字 那就可以把目前數字也丟進去等  
```cpp
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        stack<int> st;
        vector<int> result( nums.size(), -1 );
        int temp = nums.size();
        for ( int i = 0 ; i < nums.size()*2 ; i++ ) {
            if ( i == 0 ) {
                st.push(i);
            }
            else {
                
                while ( st.size() != 0 && nums[i%temp] > nums[st.top()] ) {
                    result[st.top()] = nums[i%temp];
                    st.pop();
                }
                
                if ( i < nums.size() ) {
                    st.push(i);
                }
            }
        }
        return result;
    }
};
```
