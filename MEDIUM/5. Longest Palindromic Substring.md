# [5. Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/description/)
目標 -> 回傳最長的回文子字串  
跟647題目基本一樣 只是要的結果不同  
主要就是每次找到就計算長度  
如果長度大於目前找到的就記錄一下  
也是利用DP 從後往前找  
a or aa 頭尾相同 或只有一個 -> 回文  
aba -> 頭尾同 那就看中間的是不是回文  

```cpp
class Solution {
public:
    //我直接拿647的來改
    string longestPalindrome(string s) {
        int longI = 0, longJ = 0, longM = 0;
        vector<vector<bool>> dp( s.size(), (vector<bool>( s.size(), false )) );
        for ( int i = s.size()-1 ; i >= 0 ; i-- ) {
            for ( int j = i ; j < s.size() ; j++ ) {
                // aa   -> i = 1 j = 0
                // aba  -> i = 2 j = 0 -> 兩邊相同就看中間有沒有也是回文 
                // abba -> i = 3 j = 0
                
                if ( s[i] == s[j] ) { 
                    if ( (j - i <= 1) || dp[i+1][j-1] ) {
                        dp[i][j] = true;
                        if ( abs(j-i) > longM ) {
                            longM = abs(j-i);
                            longI = i;
                            longJ = j;
                        }
                    }
                }
            }
        }
        string result = s.substr( longI, longJ - longI + 1 );
        return result;
    }
};
```
