# [61. Rotate List](https://leetcode.com/problems/rotate-list/description/)  
目標 -> 旋轉K次  
Input: head = [1,2,3,4,5], k = 2  
Output: [4,5,1,2,3]  
先走訪一次 看list有多長 並可以得到最後一個node的位置和他的上一個(pre是temp的上一個 temp是最後一個)  
把K%list的長度 有機會減少要旋轉的次數  
如果剩下0代表 轉K次會剛好回到一開始的順序 那就不用做  
否則就把temp移動到head的前面變成新的head  
且pre -> next = NULL  

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        
        if ( head == NULL ) {
            return NULL;
        }
        else if ( k == 0 ) {
            return head;
        }
        else {
            int count = 1;
            ListNode* temp = head;
            ListNode* pre = NULL;
            for ( ; temp -> next != NULL ; pre = temp, temp = temp -> next ) {
                count++;
            }

            if ( k / count != 0 && k != 1 && count != 1 ) {
                k = k % count;
            }

            if ( k != 0 ) {
                if ( pre != NULL ) {
                    pre -> next = NULL;
                    temp -> next = head;
                }
                else {
                    ;
                }

                return rotateRight( temp, k-1 );
            }
            else {
                return head;
            }

        }
    }
};
```
