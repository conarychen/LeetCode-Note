# [739. Daily Temperatures](https://leetcode.com/problems/daily-temperatures/description/)  
目標 -> 找到要等多久才會遇到比當天溫度高的天氣(每天都要)  
基本上跟[503](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0503.%20Next%20Greater%20Element%20II.md)一樣  
只是這題不用跑回頭繼續找 跑到尾沒有就是預設的0  
```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        stack<int> st;
        vector<int> result( temperatures.size(), 0 );
        for ( int i = 0 ; i < temperatures.size() ; i++ ) {
            if ( i == 0 ) {
                st.push( i );
            }
            else {
                while ( st.size() != 0 && temperatures[i] > temperatures[st.top()] ) {
                    result[st.top()] = i - st.top();
                    st.pop();
                }
                st.push( i );
            }
        }
        return result;
    }
};
```
