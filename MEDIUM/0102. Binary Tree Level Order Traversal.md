# [102. Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)  
目標 -> Level Order Traversa -> 上到下 一層一層走 node從左至右紀錄  
先放root 進vec 設定size = vec的size  
每輪要做的就是讀第一個node 記錄完後 如果他有左右子樹就推進vec  
然後pop掉 重複這個動作size次 也就是這層有幾個node做幾次  
結束後vec會剩下下一層的node  
就這樣一路做到vec空了 代表紀錄完全部了  

我感覺用deque會比較好  
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        vector<int> level;
        vector<TreeNode*> que;
        int sizeQ;
        if ( root != NULL ) {
            que.push_back( root );
        }       
        while ( que.size() != 0 ) {
            sizeQ = que.size();
            for ( int i = 0 ; i < sizeQ ; i++ ) { //只做一開始queue裡面的 = 同一層
                level.push_back( que[0] -> val );
                if ( que[0] -> left != NULL ) { //左邊有就加進queue
                    que.push_back( que[0] -> left );
                }
                if ( que[0] -> right != NULL ) { //右邊有加進queue
                    que.push_back( que[0] -> right );
                }
                que.erase( que.begin() ); //結束後移出queue
            } //結束後裡面剩下的就是下一層的
            result.push_back( level ); //將每層結果推入result
            while ( level.size() != 0 ) { 
                level.pop_back();
            }
        } 
        return result;
    }
};
```
