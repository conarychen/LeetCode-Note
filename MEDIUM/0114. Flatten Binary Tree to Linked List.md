# [114. Flatten Binary Tree to Linked List](https://leetcode.com/problems/flatten-binary-tree-to-linked-list/description/)  
目標 -> 將binary tree以preorder的順序平攤成linked list  
這邊我偷懶先travel一次把node存起來再串  
但其實邊走邊串也可以 多傳一個parent 或是用一個member變數記list的尾端串起來就好  
```cpp
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode() : val(0), left(nullptr), right(nullptr) {}
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 *     TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
 * };
 */
class Solution {
public:
    void inorder( TreeNode* head, vector<TreeNode*> &vec ) {
        if ( head == NULL ) {
            return;
        }
        vec.push_back( head );
        inorder( head -> left, vec );
        inorder( head -> right, vec );
    }
    void flatten(TreeNode* root) {
        vector<TreeNode*> vec;
        inorder( root, vec );
        for ( int i = 0 ; i < vec.size() ; i++ ) {
            vec[i] -> left = NULL;
            if ( i == vec.size()-1 ) {
                vec[i] -> right = NULL;
            }
            else {
                vec[i] -> right = vec[i+1];
            }
        }
    }
};
```
