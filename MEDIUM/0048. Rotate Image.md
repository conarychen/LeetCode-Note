# [48. Rotate Image](https://leetcode.com/problems/rotate-image/description/)  
目標 -> 旋轉矩陣 也就是圖片的旋轉  
照著公式 "沿著斜線互換 再每個橫排倒序"即可  

```cpp
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        //先沿著斜線互換 再每個橫排倒序
        int m = matrix.size(), n = matrix[0].size();
        int temp;
        for ( int i = 0 ; i < m ; i++ ) {
            
            for ( int j = i+1 ; j < n ; j++ ) {

                temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }


        int pos;
        for ( int i = 0 ; i < m ; i++ ) {
            pos = matrix[i].size()-1;
            for ( int j = 0 ; j < n/2 ; j++ ) {
                temp = matrix[i][j];
                matrix[i][j] = matrix[i][pos-j];
                matrix[i][pos-j] = temp;
            }
        }

    }
};
```
