# [6. Zigzag Conversion](https://leetcode.com/problems/zigzag-conversion/description/)
目標 -> 把input字串排成zigzag形狀( 之字形 or 鋸齒 )  
ex : "PAYPALISHIRING"
<img width="138" height="72" alt="image" src="https://github.com/user-attachments/assets/9c04d371-b769-46d2-9abe-eff0c5813677" />  
直的向下numRows個然後放右上格子直到回到頂 重複這規則即可  
我用goDown來判斷現在往哪走  如果往下那就直直往下 如果往上 就要往右上  
碰到底goDown改成false 代表要開始往上 反之改成true 代表往下  

```cpp
class Solution {
public:
    string convert(string s, int numRows) {
        vector<string> temp;
        string result;
        bool goDown = true; //store down order or uper
        for ( int i = 0; i < numRows ; i++ ) {
            temp.push_back( "" );
        }
        
        for ( int i = 0, pos = 0 ; i < s.size() ; i++ ) {
            temp[pos].push_back( s[i] );
            if ( numRows == 1 ) {
                ;
            }
            else if ( goDown && pos != numRows-1 ) {
                pos++;
            }
            else if ( goDown && pos == numRows-1 ) {
                pos--;
                goDown = false;
            }
            else if ( !goDown && pos != 0 ) {
                pos--;
            }
            else { 
                pos++;
                goDown = true;
            }
        }
        
        for ( int i = 0 ; i < temp.size() ; i++ ) {
            result.append( temp[i] );
        }
        return result;
    }
};
```
