# [38. Count and Say](https://leetcode.com/problems/count-and-say/description/)  
目標 -> 對字串進行壓縮  
規則如下  
countAndSay(1) = "1"  
countAndSay(2) = RLE of "1" = "11"  ("1"套用規則 => 1個1)  
countAndSay(3) = RLE of "11" = "21" ("11" => 2個1)  
countAndSay(4) = RLE of "21" = "1211" ("21" => 1個2 1個1)  
簡單來說壓縮成(數字的量)(數字)
利用遞迴先取得countAndSay(i-1)的值 再開始處理countAndSay(i)的部分  
遍歷一次 計算相同數字有幾個 每次換新數字就把上個數字的結果存到字串 再進行新數字的計算  

```cpp
class Solution {
public:

    string itos( int num ) {
        string result = "";
        int temp = 0;
        
        while ( num != 0 ) {
            temp = num % 10;
            num /= 10;
            result.insert( result.begin(), temp + '0' ); 
        }   //方向相反 所以要從頭插入
        if ( num == 0 && result == "" ) {
            result = "0";
        }
        return result;
    }

    string countAndSay(int n) {
        string temp = "";
        string result = "";
        if ( n == 1 ) {
            result = "1";
            return result;
        }
        else if ( n == 2 ) {
            result = "11";
            return result;
        }
        else {
            temp = countAndSay( n - 1 );
        }
        int count = 1;
        result = "";
        string test = "";
        int num = 0;
        char t = ' ';
        for ( int i = 1 ; i <= temp.size() ; i++ ) {
            if ( temp[i-1] == temp[i] && i < temp.size() ) {
                count++;
            }
            else {
                test = itos( count );
                result.append( test );
                t = temp[i-1];
                test = "";
                test.push_back( t );
                result.append( test );
                

                count = 1;
            }
        }
        return result;

    }
};
```
