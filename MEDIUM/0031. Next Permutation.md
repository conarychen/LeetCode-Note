# [31. Next Permutation](https://leetcode.com/problems/next-permutation/description/)  
目標 -> 找到下一個排列  
123為例 有123 132 213 231 312 321  
若input = 213 則 output = 231(即213的下一個排列)  
再以1234 為例 123(i)4(j)時 j > i -交換-> 1243 -i+1到尾端反轉(因為只有一位 所以結果相同)-> 1243  
12(i)43(j) j > i -交換-> 1342 -i+12到尾反轉-> 1324  (與上行是連續的執行結果)  

```cpp
class Solution {

public:
    //由後往前比 找到後(j) > 前(i)的就交換，然後i以後的反轉 
    void nextPermutation(vector<int>& nums) {
        for ( int i = nums.size()-1 ; i >= 0 ; i-- ) {
            for ( int j = nums.size()-1 ; j > i ; j-- ) {
                if ( nums[j] > nums[i] ) {
                    swap( nums[j], nums[i] );
                    reverse( nums.begin()+i+1, nums.end() );
                    return;
                }
            }
        }
        reverse( nums.begin(), nums.end() );
        return;
    }
};
```
