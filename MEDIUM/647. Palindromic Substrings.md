# [647. Palindromic Substrings](https://leetcode.com/problems/palindromic-substrings/)  
和[5](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/5.%20Longest%20Palindromic%20Substring.md)差不多  
目標 -> 算出有幾個回文子字串  
範圍i從後往前 j從1~s尾  
利用DP紀錄s[i]~s[j]這段是不是回文  
a or aa or aba 三種  
看i,j位置的字元相不相同  
如果i,j不是相鄰或同一格  
那就看一下他們中間的是不是回文(aba or abba的例子中就是看 b or bb )  
每次有找到就標記此段子字串有 然後count++即可  

```cpp
class Solution {
public:
    int countSubstrings(string s) {
        vector<vector<bool>> dp( s.size(), (vector<bool>( s.size(), false )) );
        int count = 0;
        for ( int i = s.size()-1 ; i >= 0 ; i-- ) {
            for ( int j = i ; j < s.size() ; j++ ) {
                // aa   -> i = 1 j = 0
                // aba  -> i = 2 j = 0 -> 兩邊相同就看中間有沒有也是回文 
                // abba -> i = 3 j = 0
                
                if ( s[i] == s[j] ) { 
                    if ( (j - i <= 1) || dp[i+1][j-1] ) {
                        count++;
                        dp[i][j] = true;
                    }
                }
            }
        }
        return count;
    }
};
```
