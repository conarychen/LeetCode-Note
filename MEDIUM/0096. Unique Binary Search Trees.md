# [96. Unique Binary Search Trees](https://leetcode.com/problems/unique-binary-search-trees/description/)  
目標 -> 回傳n個node可以做出幾種BST  
root -> 1種 + (左子樹 * 右子樹)  
利用DP來記錄多少node有幾種可能後就可以比單純遞迴還有效率的計算  
詳細例子的算法在下面註解  
```cpp
class Solution {
public:
    int numTrees(int n) {
        if ( n == 0 || n == 1 ) {
            return 1;
        }
        vector<int> dp(n+1);
        dp[0] = 1;
        dp[1] = 1;
        for ( int i = 2 ; i <= n ; i++ ) {
            for ( int j = 0 ; j < i ; j++ ) {
                dp[i] += dp[j] * dp[i-j-1];
            }
        }
        return dp[n];
    }
    // ex n = 3 注意是BST!!
    // root = 1 -> 左 0 右 2 -> dp[0]種可能 dp[2]種可能 -> 1 * 2 = 2
    // root = 2 -> 左 1 右 1 -> 1 * 1 = 1
    // root = 3 -> 左 2 右 0 -> 2 * 1 = 2
    // 加起來 => 2+1+2 = 5
    // 也就是 dp[n] = dp[0~n] * dp[n~0]的加總
};
```
