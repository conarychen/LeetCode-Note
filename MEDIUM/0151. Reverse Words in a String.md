# [151. Reverse Words in a String](https://leetcode.com/problems/reverse-words-in-a-string/description/)  
目標 -> 把string內的words順序反轉  
利用stringstream把空格去掉 每次只取一段不含空格的文字 即可達到取word的目的  
接著每次取到詞就插入到string開頭即可  
```cpp
class Solution {
public:
    string reverseWords(string s) {
        stringstream ss(s);
        string temp = "";
        string result = "";
        while ( ss >> temp ) { //ss 會自動省略空白 直接抓非空白的字串
            if ( result.size() == 0 ) { // 抓出來的排進去 
                result += temp;
            }
            else {
                result = temp + " " + result;
            }
            temp = "";
        }
        return result;
    }
};
```
