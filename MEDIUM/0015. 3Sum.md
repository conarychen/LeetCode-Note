# [15. 3Sum](https://leetcode.com/problems/3sum/description/)  
目標 -> 找到三個數相加為0  
一開始先對nums排序 才可以跳過重複組合(跳過連續重複開頭)  
利用two pointers  從i(開頭位置), left(i+1), right(nums.size()-1) 開始找組合  
三數和大於零 代表數字太大 -> right的值太大 所以right-1  
三數和小於零 代表數字太小 -> left+1  
等於零 找到組合存起來後 兩個指標都要動 避免找到相同的組合 -> left+1, right-1  
每次left, right移動時 也要移動到與上個位置不同值的位置才繼續做(去重複)  

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        int count = 0, left, right;
        sort( nums.begin(), nums.end() );
        for ( int i = 0 ; i < nums.size()-2 ; i++ ) {
            //跳過重複開頭 -> 因為前面有先排序才做得到
            if ( i > 0 && nums[i] == nums[i-1] ) {
                continue;
            }
            count = nums[i];
            left = i+1;
            right = nums.size()-1;
            while ( left < right && left < nums.size() && right >= 0 ) {

                if ( count+nums[left]+nums[right] == 0 ) {
                    vector<int> temp;
                    temp.push_back( nums[i] );
                    temp.push_back( nums[left] );
                    temp.push_back( nums[right] );
                    result.push_back( temp );
                    left++;
                    while( left < nums.size() && nums[left] == nums[left-1] ) {
                        left++;
                    }
                    right--;
                    while( right > 0 && nums[right] == nums[right+1] ) {
                        right--;
                    }
                }
                else if ( count+nums[left]+nums[right] < 0 ) {
                    left++;
                    while( left < nums.size() && nums[left] == nums[left-1] ) {
                        left++;
                    }
                }//每次移動雙指標都要判斷有沒有一樣的數字 因為不取重複的所以都跳過
                else {
                    right--;
                    while( right > 0 && nums[right] == nums[right+1] ) {
                        right--;
                    }
                }
            }
        }
        return result;
    }
};
```
