# [841. Keys and Rooms](https://leetcode.com/problems/keys-and-rooms/description/)  
目標 -> 進到每間房間 進去有機會得到其他間鑰匙 所以如果可以全部都進去就回傳true  
利用表格紀錄那些進去過了 加上DFS把所有能走的房間都走一遍  
最後看有沒有被標記沒進去過的即可  
```cpp
class Solution {
private:
    void dfs( vector<vector<int>>& rooms, int key, vector<bool>& door ) {
        if ( door[key] ) return; //走過就不重複走
        vector<int> keys = rooms[key];
        door[key] = true;
        for ( int i : keys ) {
            dfs( rooms, i, door );
        }
    }
public:
    bool canVisitAllRooms(vector<vector<int>>& rooms) {
        vector<bool> door( rooms.size(), false );
        dfs( rooms, 0, door );
        for ( int i = 0 ; i < door.size() ; i++ ) {
            if ( door[i] == false ) return false;
        }
        return true;
    }
};
```
