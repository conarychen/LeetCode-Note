# [50. Pow(x, n)](https://leetcode.com/problems/powx-n/description/)  
目標 -> 實作pow  
用long long避免溢位  
和[29](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0029.%20Divide%20Two%20Integers.md)很像  
每次都做平方倍來加快計算  

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        double result = 1.0;
        long long N;
        if ( n < 0 ) {
            x = 1.0 / x;
            N = (long long)n*-1;
        }
        else if ( n == 0 ) {
            result = 1.0;
        }
        else {
            N = n;
        }

        while( N > 0 ) {
            if ( N % 2 == 1 ) { //odd
                result *= x;
                N--;
            }
            x *= x;
            N /= 2;
        }

        return result;
    }
};
```
