# [53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/description/)  
目標 -> 找到最大總和的子字串  
只要加起來沒有<0就繼續加  
如果超過目前的最大值就存成最大值  
如果加起來<0  
那就可以重新計算 找新的子字串  
```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int max = INT_MIN;
        int count = 0;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            count += nums[i];
            if ( count > max ) {
                max = count;
            }
            if ( count < 0 ) {
                count = 0;
            }
        }
        return max;
    }
};
```
