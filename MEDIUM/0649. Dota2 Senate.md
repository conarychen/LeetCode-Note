# [649. Dota2 Senate](https://leetcode.com/problems/dota2-senate/description/)  
目標 -> 按照題目要求的玩法 預測最後會是誰贏  
玩法簡單來說 有R D兩種棋子 按照順序來行動  
只要兩種棋子都還有那就要繼續 直到剩下一種棋子  
每種棋子要做的就是找自己後面的敵對棋子並把它砍掉 最終只剩下一種即獲勝  
所以這邊我以r d來表示這兩種棋子是否還有  
以count來記下次遇到誰要砍掉 我以r為主 所以正數代表前面是r 如果遇到d就要削去d 反之則是削去r  
且如果碰到的棋子是可以行動的(也就是不是被削去的) 代表下輪還會有這種棋子可以行動 所以r d對應的標記就可以改成true  
直到有一方是false 遊戲就結束  
```cpp
class Solution {
public:
    string predictPartyVictory(string senate) {
        bool r = true, d = true;
        int count = 0; // count r的數量 -> > 0時 遇到d 就要消去d
        while ( r && d ) {
            r = false;
            d = false;
            for ( int i = 0 ; i < senate.size() ; i++ ) {
                
                if ( senate[i] == 'R' ) {
                    if ( count < 0 ) { //現在的R被消滅
                        senate[i] = '0';
                    }
                    else { //只要有一個R和一個D倖存 那就會有下一輪
                        r = true;
                    }
                    count++;
                }
                else if ( senate[i] == 'D' ) {
                    if ( count > 0 ) { //現在的D被消滅
                        senate[i] = '0';
                    }
                    else { //同上 
                        d = true;
                    }
                    count--;
                }
            }
        }
        return r ? "Radiant" : "Dire";
    }
};
```
