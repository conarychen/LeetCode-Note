# [179. Largest Number](https://leetcode.com/problems/largest-number/description/)  
目標 -> 找出nums中數字可以組成的最大數  
因為可能會很大 所以轉成String處理  
問題拆成最小的情況就是兩數  
兩數的情況下就是比 ab or ba 看誰大選誰  
所以照這個邏輯寫一個比較函式將nums排列後  
拼回字串即可  
result == "0" && str[i] == "0" -> 如果已經是0 那後面又接0變00就不對  
```cpp
class Solution {
public:
    static bool compare( string a, string b ) {
        return a + b > b + a;
    }
    // "1" ,"2" -> "12" or "21" -> "21" is bigger
    string itos( int num ) {
        stringstream ss;
        ss << num;
        return ss.str();
    }
    string largestNumber(vector<int>& nums) {
        vector<string> str;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            str.push_back( itos(nums[i]) );
        }
        sort( str.begin(), str.end(), compare );
        string result = "";
        for ( int i = 0 ; i < str.size() ; i++ ) {
            if ( result == "0" && str[i] == "0" ) {
                ;
            }
            else {
                result += str[i];
            }
            
        }
        return result;
    }
};
```
