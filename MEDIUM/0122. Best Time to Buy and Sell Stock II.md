# [122. Best Time to Buy and Sell Stock II](https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/description/)  
目標 -> 每天可買賣股票 同時間只能持有一張股票 找出最大獲利  
有DP greedy兩種方法 下面都有 主要想法註解裡也有  
greedy就是只要有獲利我就拿 所以可以看成折線圖 只取斜率為正的部分  
DP的下面有  
```cpp
class Solution {
public:
    // Greedy 當折線圖看 ex:7,1,5,3,6,4
    // 7 -> 1 -> 5 -> 3 -> 6 -> 4
    //   -    +    -    +    -
    // -的時候就不拿 只拿正數差額
    /*
        int result = 0;
        for ( int i = 1 ; i < prices.size() ; i++ ) {
            if ( prices[i] - prices[i-1] > 0 ) {
                result += prices[i] - prices[i-1];
            }
        }
        return result;    
    */
    //DP
    int maxProfit(vector<int>& prices) {
        vector<vector<int>> dp( prices.size(), vector<int>(2,0) );
        //[i][j] -> i = 第幾天, j = 當天有沒有持股
        // base case
        dp[0][0] = 0; //第一天沒買 = 0
        dp[0][1] = -prices[0]; //第一天買了 資產 = -價格
        for ( int i = 1 ; i < prices.size() ; i++ ) {
            //今天沒持股 = 昨天沒買且今天沒買 or 昨天買了今天賣掉
            dp[i][0] = max( dp[i-1][0], dp[i-1][1] + prices[i] );
            //今天有 = 昨天有買且今天沒賣 or 昨天沒買+今天買
            dp[i][1] = max( dp[i-1][1], dp[i-1][0] - prices[i] );
        }
        // 另一個可能只有花錢會改變 不會有利潤上的增加
        return dp[prices.size()-1][0];
    }
};
```
