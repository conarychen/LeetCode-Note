# [274. H-Index](https://leetcode.com/problems/h-index/description/)  
目標 -> 按照H-Index定義來計算h index  
這題的敘述很亂 其實看不太懂  
簡單來說 假如說有5篇論文 他們的被引用次數為[0,1,3,5,6]  
h index要取 有h篇論文獲得h次以上的引用 這提要求最大的h值  
所以上面例子最大可以得到的就是3 也就是有三篇以上的論文獲得三次以上的引用(3,5,6這三筆)  
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        sort( citations.begin(), citations.end() );
        unordered_map<int,int> mp; // <index, num of right side datas
        int maxH = 0;
        for ( int i = 0 ; i < citations.size() ; i++ ) {
            mp[i] = citations.size()-i;
        }
        for ( auto &[key, val]:mp ) {
            if ( min( val, citations[key]) > maxH ) {
                maxH = min( val, citations[key]);
            }
        }
        return maxH;
    }
    // 0 1 3 5 6 -> 3的右邊含自己有3 代表 至少有三篇引用三次以上 H = 3
    // 100 -> 100右邊含自己只有1 代表 至少有一篇引用一次以上 H = 1
    // 結論 取這個 -> min( val, citations[key]) > maxH
};
```
