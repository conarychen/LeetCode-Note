# [201. Bitwise AND of Numbers Range](https://leetcode.com/problems/bitwise-and-of-numbers-range/description/)  
目標 -> 求目標範圍內[left, right]的所有數字的and  
如註解內的例子  
i&i-1 會發現因為這兩數差1 所以結果會消去i最右側的1  
也就是連續兩數中比較大的那一方右邊第一個1以右的部分都不會相同  
如果像是100(4) 011(3) 也一樣 4的第一個1以右都不同 所以會是000  
所以若[2,4] 在4 3的結果就已經小於2本身 所以就可以當答案了  
因為結果一定是小於等於小的數  
```cpp
class Solution {
public:
    int rangeBitwiseAnd(int left, int right) {
        if ( left == right ) {
            return left;
        }
        // right &= right-1 --> 削掉最右邊的1
        // ex 7 -> 00111
        //    6 -> 00110
        //      -> 00110 
        while ( right > left ) {
            right = right & (right-1);
            
        }
        return right;
    }
};
```
