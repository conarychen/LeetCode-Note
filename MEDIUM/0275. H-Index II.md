# [275. H-Index II](https://leetcode.com/problems/h-index-ii/description/)  
和[274](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0274.%20H-Index.md)差在此題input有排序  
所以我直接拿274來用  
但其實排序後可以用binary search來找  
簡單來說要找citations[mid] >= n-mid (n = citations.size()-1)
```cpp
class Solution {
public:
    int hIndex(vector<int>& citations) {
        unordered_map<int,int> mp; // <index, num of right side datas
        int maxH = 0;
        for ( int i = 0 ; i < citations.size() ; i++ ) {
            mp[i] = citations.size()-i;
        }
        for ( auto &[key, val]:mp ) {
            if ( min( val, citations[key]) > maxH ) {
                maxH = min( val, citations[key]);
            }
        }
        return maxH;
    }
};
```
