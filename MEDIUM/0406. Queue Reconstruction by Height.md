# [406. Queue Reconstruction by Height](https://leetcode.com/problems/queue-reconstruction-by-height/description/)  
目標 -> 每個人的資料為[身高,排在自己前面身高大於等於自己的人數] 滿足每個人的條件將資料排序  
先簡單按照身高排序 如果身高相同 第二個資料小的排前面(因為這樣符合要求)  
接著照順序一個一個放  
如果第i人的位置大於他的第二筆資料(也就代表這個位置在他前面的人太多了)  
那就把他移到他第二筆資料的位置上(ex i = 3 但他的資料是[170,2] 那這樣他前面會有三人 不行 所以把它插入到i = 2的位置)  
否則就直接丟最後面即可  
```cpp
class Solution {
public:
    static bool compareV( vector<int> &a, vector<int> &b ) {
        if ( a[0] != b[0] ) return a[0] > b[0];
        else return a[1] < b[1]; 
    }
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        sort( people.begin(), people.end(), compareV );
        vector<vector<int>> result;
        result.push_back( people[0] );
        for ( int i = 1 ; i < people.size() ; i++ ) {
            if ( people[i][1] < i ) {
                result.insert( result.begin() + people[i][1], people[i] );
            }
            else {
                result.push_back( people[i] );
            }
        }
        return result;
    }
};
```
