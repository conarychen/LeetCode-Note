# [237. Delete Node in a Linked List](https://leetcode.com/problems/delete-node-in-a-linked-list/description/)  
目標 -> 刪除傳入的節點本身 並保持linked list連接  
因為沒有給head 所以沒辦法用上個節點與下個節點連接的方式  
那就換個方法 把下個節點的內容複製過來 刪除下個節點  
題目有說明 要刪除的不會是tail  
```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    void deleteNode(ListNode* node) {
        // copy next node's content to current one
        // and connect current and next next one ( if it's exist )
        // then delete next one
        // 1 2(cur) 3 4 -> 1 3 3 4 -> 1 3 (3) 4 -> 1 3 4 ( 3 -> delete )
        ListNode* temp = node -> next;
        node -> val = temp -> val;
        if ( temp -> next != NULL ) {

            node -> next = temp -> next;
        }
        else {
            node -> next = NULL;
        }
        delete( temp );
        
        
    }
};
```
