# [238. Product of Array Except Self]()  
目標 -> 得出所有除了自己以外的乘積  
順反向各跑一次即可 temp為每一格的累積乘積 -> temp = 0~(i-1)的乘積    
順向 除了i=0的時候直接存 其他都存temp*前一個存的內容 就可以取得每格的左側乘積  
反向 同上 只是換從尾段開始 第一個因為沒有右側的數了 所以temp不需要乘上任何東西 直接乘回result  
其他部分就一樣 讓temp算出右邊乘積後 乘回結果  
```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        vector<int> result( nums.size(), 0 );
        int temp = 1;
        for ( int i = 0 ; i < nums.size() ; i++ ) { //left part product
            if ( i != 0 ) {
                temp *= nums[i-1];
            }
            result[i] = temp;
        }

        temp = 1;
        for ( int i = nums.size()-1 ; i >= 0 ; i-- ) { //right part product
            if ( i != nums.size()-1 ) {
                temp *= nums[i+1];
            }
            result[i] *= temp;
        }

        // result = nums[i]left product * nums[i]right product
        return result;
    }
};
```
