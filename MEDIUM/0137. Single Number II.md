# [137. Single Number II](https://leetcode.com/problems/single-number-ii/description/)  
目標 -> 數列中 只有一個只出現一次 其他都會出現三次  
這題解法很特別 用32bits來算 每個數都用bits來數 每個bit只要超過3就重製為0  
變相把出現三次的數清除掉  
所以最後其實只會剩下答案的bits 再用or把數放回int變數裡  
這裡先用unsigned int再轉換 因為怕會溢位  
```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int bits[32] = {0};
        unsigned int result = 0;
        // 每個bit分開算出現次數
        // 因為除了一個只出現一次外 其他都三次
        // 所以可以只記0~2 或是最後%3
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            for ( int j = 0 ; j < 32 ; j++ ) {
                bits[j] += ( nums[i] >> j ) & 1;
                if ( bits[j] == 3 ) {
                    bits[j] = 0;
                }
            }
        }
        // 用OR來把每個位元的1放回結果
        // 先用unsugned int 避免OVERFLOW 最後再轉成INT回傳
        for ( int i = 0 ; i < 32 ; i++ ) {
            result |= (bits[i] << i);  
            //cout << bitset<32>(result) << endl;  
        }

        return (int)result;
    }
};
```
