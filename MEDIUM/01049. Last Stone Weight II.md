# [1049. Last Stone Weight II](https://leetcode.com/problems/last-stone-weight-ii/description/)  
目標 -> 找出最小的石頭  
兩塊石頭互砸 會剩下大-小的重量  
找出最小能多小  
基本和[416](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0416.%20Partition%20Equal%20Subset%20Sum.md)差不多  
差在這邊是要回傳最小的數值  
但想法上一樣 只要把石頭總和分成一半 如果可以找到一半量總和的石頭 就代表可以取到最小的石頭  
```cpp
class Solution {
public:
// 基本上和416一樣 差在回傳
    int lastStoneWeightII(vector<int>& stones) {
        int tar = 0;
        for ( int i = 0 ; i < stones.size() ; i++ ) {
            tar += stones[i];
        }
        int sum = tar;
        tar /= 2;
        vector<int> dp( tar+1, 0 );
  
        for ( int i = 0 ; i < stones.size() ; i++ ) {
            
            // j >= nums[i] --> 下面的運算才不會出現dp[-1]等等的情況
            for ( int j = dp.size()-1 ; j >= stones[i] ; j-- ) {
                dp[j] = max( dp[j], dp[j-stones[i]]+stones[i] );
            }
        }
        return sum - dp[tar] - dp[tar];
    }
};
```
