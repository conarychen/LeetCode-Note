# [763. Partition Labels](https://leetcode.com/problems/partition-labels/description/)  
目標 -> 把字串分區 每區內的字母不會重複  
我先記錄每個字母最後出現的位置  
接著跑一遍字串 用count當成切點  
count先初始化是'a'最後出現的位置  
途中如果出現更遠的字母就要替換count的值  
直到 i == count 代表這是最遠的了 那就可以切這裡 也就是把位置存到result  
```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        vector<int> cal( 26, 0 );
        vector<int> result;

        for ( int i = 0 ; i < s.size() ; i++ ) {
            cal[(int)(s[i]-'a')] = i;
        }
        int count = 0, start = 0; 
        for ( int i = 0 ; i < s.size() ; i++ ) {
            if ( cal[(int)(s[i]-'a')] > count ) {
                count = cal[(int)(s[i]-'a')];
            }
            if ( count == i ) {
                if ( result.size() == 0 ) {
                    result.push_back( i+1 );
                }
                else {
                    result.push_back( i-start+1 );
                }
                start = i+1;
                count = 0;
            }
        }
        return result;
    }
};
```
