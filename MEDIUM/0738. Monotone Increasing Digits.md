# [738. Monotone Increasing Digits](https://leetcode.com/problems/monotone-increasing-digits/description/)  
目標 -> 找小於n的最大單調遞增的數  
單調遞增就是每個數從左到右都要是遞增 ex 1234 1679等等
如果題目給10 那1<0 並沒有遞增 所以就要找小於10的9  
解法在下面註解裡  
簡單來說 遇到前面比較大的 就把前面-1 然後後面的數變成9(因為可以重複 像是299就是可以的答案)  
所以先用一個flag紀錄要從哪個位置開始改成9  
每次有遇到前面比較大的就前面-1 flag的位置=後面數的位置 最後再從flag的位置開始到最後都改成9即可  
```cpp
class Solution {
public:
    int monotoneIncreasingDigits(int n) {
        string temp = to_string(n);
        int mark = -1;
        //後往前推 
        // 332 -> 2 < 3 -> 3-1 且標記2的位置(最後一次從標記位置到尾改成9)
        // 32(2m) -> 2 < 3 -> 2(2m)2 -> 從m位置(含)以後全改9
        // --> 299
        for ( int i = temp.size()-1 ; i > 0 ; i-- ) {
            if ( temp[i] < temp[i-1] ) {
                mark = i;
                temp[i-1]--;
            }
        }
        for ( int i = mark ; i < temp.size() ; i++ ) {
            temp[i] = '9';
        }
        return stoi( temp );
    }
};
```
