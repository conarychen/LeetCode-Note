# [452. Minimum Number of Arrows to Burst Balloons](https://leetcode.com/problems/minimum-number-of-arrows-to-burst-balloons/description/)  
目標 -> 最少用幾隻箭可以射破所有氣球  
input為每個氣球的寬度 也就是x軸上占據的空間  
!!!注意如果邊界交疊一樣可以一箭打破兩個 像是[1,2][2,3] 
和[435](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0435.%20Non-overlapping%20Intervals.md)有點像 只是求的條件不同  
先以最左邊的x來排序 一樣用count來記錄要用幾隻箭  
用i的頭跟i-1的尾相比 沒有重疊的部分就要多一隻箭 所以count++  
否則有重疊的話 就把i的尾跟i-1的尾取小的 等於是說i的氣球變成要射在[i頭~(i尾ori-1尾)]之間  
```cpp
class Solution {
private:
    static bool cmp( vector<int> & a, vector<int> & b ) {
        return a[0] < b[0];
    }
public:
    int findMinArrowShots(vector<vector<int>>& points) {
        if ( points.size() < 2 ) {
            return 1;
        }
        int count = 1;
        sort( points.begin(), points.end(), cmp );
        for ( int i = 1 ; i < points.size() && points.size() >= 2 ; i++ ) {
            if ( points[i][0] > points[i-1][1]) {
                count++;
            }
            else {
                points[i][1] = min( points[i][1], points[i-1][1] );
            }
    
        }
        return count;
    }
};
```
