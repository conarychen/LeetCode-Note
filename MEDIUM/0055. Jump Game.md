# [55. Jump Game](https://leetcode.com/problems/jump-game/description/)  
與[45](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0045.%20Jump%20Game%20II.md)類似  
差在45保證有解所以求最小步數  
而這題求能否到達  
這邊我從尾端往回推  
如果最後回推到開頭 代表可以走到終點  
詳細註解裡有  

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int maxPos = nums.size()-1;
        // greedy from back to forward
        // [2,3,1,1,4]
        // if we can reach pos == 3 then we can go to pos == 4
        // so we reset the target to pos == 3
        // do this until we are at pos == 0 
        for ( int i = nums.size()-2 ; i >= 0 ; i-- ) {
            if ( i + nums[i] >= maxPos ) {
                maxPos = i;
            }
        }
        return maxPos == 0; // if it's 0 means we reach the goal
    }
};
```
