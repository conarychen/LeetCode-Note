# [494. Target Sum](https://leetcode.com/problems/target-sum/description/)  
目標 -> 找到nums內可以組成target的組合  
這題和[416](https://github.com/conarychen/LeetCode-Note/blob/main/MEDIUM/0416.%20Partition%20Equal%20Subset%20Sum.md)很像  
一樣是背包問題 只要能塞滿目標包包就代表有解  
因為不能重複拿(01背包)所以一樣是從後往前處理DP  
但這題的DP式我還有點不太懂 還需要再多想想  
```cpp
class Solution {
public:
    //還是不太明白轉移式怎麼出來的
    int findTargetSumWays(vector<int>& nums, int target) {

        int sum = 0;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            sum += nums[i];
        }
        

        if ( abs(target) > sum ) return 0; //target根本達不到的情況
        //nums會可以分成left - right = target
        //              left + right = sum   --> left = (sum+target)/2
        // 也就是背包的容量 只要確定有解 那找到總和為left的組合就可解
        if ( (sum+target) % 2 != 0 ) return 0;
        
        int leftsize = (sum+target)/2;
        vector<int> dp( leftsize+1, 0 );
        dp[0] = 1;
        for ( int i = 0 ; i < nums.size() ; i++ ) {
            for ( int j = leftsize ; j >= nums[i] ; j-- ) {
                //取j-nums[i]位置裡的次數加上原本dp[j]內的次數 就是目前i可以得到的次數
                dp[j] += dp[j-nums[i]];
            }
        }
        return dp[leftsize];

    }
};
```
