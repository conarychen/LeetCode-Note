# [209. Minimum Size Subarray Sum](https://leetcode.com/problems/minimum-size-subarray-sum/description/)  
目標 -> 找到總和>=target的subarray  
所以先從頭開始加 加到>=target就可以記錄長度  
接著從頭開始丟 如果丟了還是>=target就可以更新紀錄  
值到<target那就往後再抓新的數加入即可  
```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int start = 0, end = 0, result = INT_MAX;
        int temp = 0;
        for ( ; end < nums.size() ; end++ ) {
            temp += nums[end];
            while ( temp >= target ) {
                if ( end-start+1 < result ) {
                    result = end-start+1;
                }
                temp -= nums[start++];
            }

        }
        if ( result == INT_MAX ) {
            result = 0;
        }
        return result;
    }
};
```
