# [0174. Dungeon Game]()  
目標 -> 從最左上走到最右下 每格都有數字代表加血或扣血 找到最少需要多少血量  
用DP 從右下往左上回推  
先初始化dp[0][i]和dp[0][i] -> 因為只有單一路徑 所以直接推  
扣完血如果是負的 那就放1(因為活著最少需要1滴血) 否則取扣完的血量  
好了就從右下往左、左上比較看哪條路需要最少血  
最後dp[0][0]就會是我們要的最低起始血量

```cpp
class Solution {
public:
    int calculateMinimumHP(vector<vector<int>>& dungeon) {
        int m = dungeon.size(), n = dungeon[0].size();
        vector<vector<int>> dp( m, vector<int>( n, 0 ) );
        int temp = 0;
        if ( dungeon[m-1][n-1] < 0 ) {
            dp[m-1][n-1] = abs( dungeon[m-1][n-1] ) + 1;
        }
        else {
            dp[m-1][n-1] = 1;
        }
        for ( int i = m-2 ; i >= 0 ; i-- ) { //last col
            dp[i][n-1] = max( 1, dp[i+1][n-1] - dungeon[i][n-1] );
        }
        for ( int i = n-2 ; i >= 0 ; i-- ) { //last row
            dp[m-1][i] = max( 1, dp[m-1][i+1] - dungeon[m-1][i] );
        }
        for ( int i = m-2 ; i >= 0 ; i-- ) {
            for ( int j = n-2 ; j >= 0 ; j-- ) {
                dp[i][j] = max( 1, min( dp[i+1][j], dp[i][j+1] ) - dungeon[i][j] );
            }
        }
        return dp[0][0];
    }
};
```
