# [135. Candy](https://leetcode.com/problems/candy/description/)  
ratings -> 每個孩子的評分  
目標 -> 發糖果給每個小孩 每個小孩至少要一顆糖 評分較高的小孩要比旁邊的人更多 計算最少需要多少糖  
如註解內說明 分成兩趟即可完成 
```cpp
class Solution {
public:
    //分兩趟 左 -> 右 的右比左 跟 右 -> 左 的左比右
    //!! 不要同時
    int candy(vector<int>& ratings) {
        vector<int> counting( ratings.size(), 1 );
        for ( int i = 1 ; i < ratings.size() ; i++ ) {
            if ( ratings[i] > ratings[i-1] ) {
                counting[i] = max( counting[i], counting[i-1]+1 );
            }
        }
        for ( int i = ratings.size()-2 ; i >= 0 ; i-- ) {
            if ( ratings[i] > ratings[i+1] ) {
                counting[i] = max( counting[i], counting[i+1]+1 );
            }
        }
        int result = 0;
        for ( int i = 0 ; i < counting.size() ; i++ ) {
            result += counting[i];
        }
        return result;
    }
};
```
