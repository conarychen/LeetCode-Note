# [154. Find Minimum in Rotated Sorted Array II]()  
Input -> 可能旋轉過的int array  
Output -> 找出array中最小的數  
先找有沒有旋轉過 如果沒旋轉過array會是遞增數列  
所以只要找到nums[i] > nums[i+1] 就代表是有旋轉過  
而且最小值就在nums[i+1]  
如果沒旋轉過 代表是正常的遞增數列 答案也就是array的第一個元素nums[0]

```cpp
class Solution {
public:
    int findMin(vector<int>& nums) {
        int left = 0, right = nums.size()-1, mid = 0;
        int result = 0, pivot = -1;
        bool isEnd = false;


        if ( nums.size() == 1 ) {
            ;
        }
        else {
            //find pivot  ex 34512 -> my pivot means 4th place = 1
            for ( int i = 0 ; i+1 < nums.size() ; i++ ) {
                if ( nums.size() > 1 && nums[i] > nums[i+1] ) {
                    pivot = i+1; 
                    i = nums.size();
                    //find first one
                }
            }
        }

        if ( pivot != -1 ) {
            result = nums[pivot];
        }
        else {
            result = nums[0];
        }

        return result;
    }
};
```
